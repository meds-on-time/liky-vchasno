# «Ліки вчасно» — стартовий DevOps-каркас (SCRUM-34, SCRUM-35)

Це **інфраструктурна заготовка**, а **не готовий продукт**. У ній є FastAPI, перевірка доступності PostgreSQL, автоматичні міграції Alembic, мінімальний бот aiogram із командою `/start` та порожній цикл планувальника. Розклади, ліки, нагадування, авторизація і сповіщення поки **не реалізовані**: ці частини додадуть Маша, Тарас та інші учасники за своїми задачами.

## Що потрібно

- Docker Desktop або Docker Engine + Docker Compose;
- вільний локальний порт 8000.

## Локальний запуск

**Windows PowerShell:**

```powershell
Copy-Item .env.example .env
docker compose up --build
```

**Linux/macOS:**

```bash
cp .env.example .env
docker compose up --build
```

Для початкової демонстрації API і PostgreSQL команда `docker compose up` працює навіть без копіювання `.env`, використовуючи **тестові** значення за замовчуванням. Два контейнери: `app` (FastAPI + aiogram + планувальник) і `db` (PostgreSQL). `alembic upgrade head` виконується автоматично перед запуском сервера.

Перевір:
- Swagger: http://localhost:8000/docs
- Health-check: http://localhost:8000/health
- Очікувана відповідь без токена: `{"status":"ok","database":"connected","bot_enabled":false}`.

## Як під'єднати Telegram-бота

1. Отримай токен власного тестового бота в BotFather.
2. У **локальному** файлі `.env` заповни `BOT_TOKEN=твій_токен`.
3. Виконай `docker compose up --build` (або `docker compose up -d --force-recreate`).
4. Надішли боту `/start`: він має відповісти, що каркас під'єднаний. **Справжніх нагадувань у каркасі ще немає.**

`.env` у `.gitignore` та `.dockerignore`, його не можна комітити. `.env.example` містить лише приклад локальних налаштувань — не справжні паролі. Під час зміни локального пароля PostgreSQL одночасно онови пароль у `DATABASE_URL`. Для production потрібні окремі секрети, а не значення з прикладу.

## Корисні команди

```bash
docker compose ps
docker compose logs -f app
docker compose exec app alembic current
docker compose down
```

**Увага:** `docker compose down -v` видаляє також локальні дані PostgreSQL.

## Як додаватиме код команда

- **Маша, Backend:** додає моделі й API у `app/`, налаштовує `target_metadata` в `alembic/env.py` на `Base.metadata` своїх SQLAlchemy-моделей; створює наступні реальні міграції. Під час інтеграції потрібно зберегти запуск API, бота та планувальника в одному контейнері.
- **Тарас, бот/веб:** розширює `app/bot.py` з aiogram 3; додає обробники `taken:{intake_id}` і `snooze:{intake_id}` відповідно до контракту. React не входить до поточної задачі SCRUM-35: за затвердженою схемою тут **два** контейнери.
- **Саша, BA:** погоджує UML і схему БД.
- **Макс, QA:** розробляє тести, зокрема 20+ модульних і інтеграційні. Наявні два smoke-тести **не замінюють** вимоги курсу.
- **Катя, DevOps:** захист `main` (SCRUM-34), Docker (SCRUM-35), далі CI (SCRUM-36) і деплой (SCRUM-37).

Для обчислення часу прийому треба використовувати timezone-aware дати в `Europe/Kyiv`. Наявність `TZ` у контейнері **сама по собі не реалізує** правило нагадувань.

## Перевірка критеріїв SCRUM-35

1. Зроби чистий клон у тимчасову папку.
2. За потреби скопіюй `.env.example` у `.env`.
3. Запусти `docker compose up --build`.
4. Перевір `docker compose ps`: сервіси `db` і `app` мають бути `healthy`.
5. Відкрий `/docs` (HTTP 200) і `/health` (HTTP 200, `database: connected`).
6. У `git status --ignored` перевір, що `.env` **ігнорується**, `.env.example` відстежується.
7. Додай справжній `BOT_TOKEN` **тільки локально** та продемонструй `/start` у Telegram.
8. Відкрий PR із `SCRUM-35` у назві, дочекайся схвалення іншого учасника та перевірок CI (коли SCRUM-36 вже готова).

## Чого ще немає

Немає справжнього планувальника прийомів ліків, API для ліків/користувачів, React, повноцінних тестів, реальної схеми БД і production-секретів. Це свідомо залишено для подальших Jira-задач.

**Обмеження перевірки:** у середовищі створення цього архіву немає Docker, тому успішний end-to-end запуск контейнерів ще потрібно підтвердити на комп'ютері з Docker або у CI. Без реального токена Telegram polling вимкнений, хоча API та база працюватимуть.
